# 東向き1R ウォークスルー

`reference/floorplan.jpg` の間取り図を実寸に起こし、ブラウザ上を自由に歩き回れる
一人称の内覧システム。単一 HTML（`index.html`）で完結し、外部アセットは持たない。
テクスチャ・空・街並みはすべて実行時に Canvas で生成している。

**公開先（Artifact）**: https://claude.ai/code/artifact/2374da93-0a6d-4d73-8017-a7fab551f72e

---

## 1. 図面から寸法を起こす

間取り図には寸法線がない。そこで公開値の 2 つ —— **専有 26.40㎡** と
**洋室 10.6帖** —— を拘束条件として躯体を決めた。

| 項目 | 値 |
|---|---|
| 内法エンベロープ | **3.20 m（W）× 8.25 m（D）= 26.40㎡**（一致） |
| 天井高 | 2.45 m |
| バルコニー | 奥行 1.40 m・隅切りあり |
| 方位 | バルコニー面 = 東（+Z が東、+X が南） |

洋室 10.6帖 の検算（1帖 = 1.62㎡ → 17.17㎡）:

```
洋室本体   3.20 × 3.70 = 11.84
廊下       1.00 × 3.20 =  3.20
キッチン帯 0.95 × 3.20 =  3.04
                        ------
オープン部分の合計       18.08 ㎡
− 洗濯機置場・冷蔵庫置場の設置面積（約 0.9）
                        ------
                         17.2 ㎡ = 10.6 帖   ← 公開値と一致
```

### 室割り（すべて m、原点は玄関ドア側の西角）

| 室 | X 範囲 | Z 範囲 | 面積 |
|---|---|---|---|
| トイレ | 0.00–1.25 | 0.00–1.35 | 1.69㎡ |
| 洗面脱衣 | 0.00–1.25 | 1.35–2.20 | 1.06㎡ |
| 浴室（1216 相当） | 0.00–1.25 | 2.20–3.80 | 2.00㎡ |
| クローゼット | 0.00–1.25 | 3.80–4.55 | 0.94㎡ |
| 玄関 | 1.25–3.20 | 0.00–1.35 | 2.63㎡ |
| 廊下 | 1.25–2.25 | 1.35–4.55 | 3.20㎡ |
| キッチン帯（洗濯機・冷蔵庫・キッチン） | 2.25–3.20 | 1.35–4.55 | 3.04㎡ |
| 洋室 | 0.00–3.20 | 4.55–8.25 | 11.84㎡ |
| | | **合計** | **26.40㎡** |

図面の記号はすべて 3D に落としてある：上がり框（150 mm の段差）、
MB（メーターボックス）パネル、洗濯機置場の防水パン、2口コンロ、
1216 ユニットバスの浴槽、折戸のクローゼット、バルコニーの隅切り。

> **注意**: これは図面からの妥当な復元であって、実測図ではない。
> 図面に寸法線がない以上、個々の内法は ±100 mm 程度の幅を持つ。
> 契約判断には使わないこと。

## 2. 操作

| 入力 | 動作 |
|---|---|
| `W` `A` `S` `D` / 矢印 | 移動 |
| マウス（クリックでポインタロック） | 視点 |
| `Shift` | 走る |
| `C` | しゃがむ（子ども目線・低い窓の確認） |
| `1`–`6` | 玄関 / 洗面 / 浴室 / キッチン / 洋室 / バルコニーへ移動 |
| `T` | 自動内覧ツアー |
| `V` | 縦 9:16（SNS 収録）モード |
| `M` | 間取り図の表示切替 |
| `Esc` | ツアー終了 / ポインタロック解除 |
| スマホ | 左下スティックで移動、画面ドラッグで視点 |

ドアは近づくと自動で開く（開き勝手も図面どおり）。掃き出し窓は 2 枚引き違いで、
開くとバルコニーに出られる。

## 3. 機能

- **時刻スライダー（05:00–20:00）** — 東向きの日射を再現する。太陽方位は
  6時に真東（バルコニー正面）、12時に真南、18時に真西。朝の光が床のどこまで
  届くかを実際に確かめられるのが、この向きの物件で唯一意味のある確認項目。
- **室内照明** — 自動（日射量に連動）／常時 ON を切替。
- **家具 ON/OFF** — 空室状態での寸法感を確認できる。
- **室名ラベル** — 各室に面積・サイズを浮かせる。
- **間取り図ミニマップ** — 実際の間取り図として描き起こし（壁のポシェ、
  建具の開き勝手、方位）、現在地と視野を重ねる。
- **自動内覧ツアー** — 44 秒・9 カットの固定カメラワーク。画面収録用。

## 4. 動かす

```bash
# そのままブラウザで開く
open floorplan3d/index.html

# もしくはローカルサーバー経由
npx http-server floorplan3d -p 8080
```

`index.html` は Artifact のラッパー（`<!doctype>`／`<head>`）を前提に
本文だけを持つ断片形式だが、ブラウザが暗黙に補完するため直接開いても動く。

外部依存は 2 つだけ、いずれも CDN から:

- three.js r128（cdnjs）
- Google Fonts: Shippori Mincho / Zen Kaku Gothic New / IBM Plex Mono

## 5. SNS 用の動画

依頼の後半「作成の様子を動画で撮りつつ、バズりそうな動画も作って」については、
画面収録そのものはこの環境からは実行できない。代わりに、**収録すれば成立する
状態**まで作り込んである（縦 9:16 モード、44 秒のカメラワーク、カット割りに
合わせたテロップ）。撮影手順と台本は [`SNS_SHOTLIST.md`](SNS_SHOTLIST.md) に。
